# v4 경고 진입 조건 조정

## 변경과 근거

새 후보 모델·스케일러·분류 임계값(0.02)은 바꾸지 않았다.
v3는 모델 신호가 0.5초 지속되면 첫 경고가 가능했고, 별도의 눈 감김
규칙은 1초에 경고했다. 모델 경로만 늦춰도 눈 감김 경로로 같은 사건이
경고되어 session_10의 새 오경보 6회가 줄지 않았다.

v4는 두 경로에 최소 1.25초를 적용한다.

- 모델 신호 지속 시간: 1.25 / 1.75 / 2.25초
- 양쪽 눈 감김 지속 시간: 1.25 / 2 / 3초
- 확실한 눈 재개방 0.5초 후 해제는 유지
- 눈 감김 기준과 재개방 기준 사이의 경계 상태가 0.15초 이상 유지되면
  눈 감김 진행 타이머를 초기화한다. 이미 발생한 경고의 해제 조건은 유지한다.

짧은 경계 흔들림은 허용하지만, 경계 상태를 무기한 눈 감김으로 누적하지 않는다.
코드 버전은 `personal-ear-model-v4`다. 서버 `/health`와 클라이언트 출력·CSV에서
실제 최소 경고 시간을 확인할 수 있다.

## session_10에서 조건 비교

같은 EAR·보정값·기록된 후보 점수를 사용해 규칙만 비교했다.
회복 구간도 프레임 오류에 포함했다. 지연은 라벨 전환 첫 수신 프레임 기준이다.

| 조건 | 새 정상 구간 경고 | 평균 첫 경고 지연 | 완료 시험 성공/누락 | 프레임 정확도 |
|---|---:|---:|---:|---:|
| v3 | 6 | 0.757초 | 4/0 | 92.43% |
| 최소 0.75초, 경계 타이머 초기화 | 6 | 0.999초 | 4/0 | 92.58% |
| 최소 1.0초, 경계 타이머 초기화 | 5 | 1.247초 | 4/0 | 92.85% |
| **v4: 최소 1.25초** | **4** | **1.490초** | **4/0** | **93.04%** |
| 최소 1.5초 | 3 | 1.735초 | 4/0 | 93.15% |
| 최소 2.0초 | 2 | 2.233초 | 4/0 | 93.32% |

더 긴 대기는 오경보를 더 줄이지만 경고도 더 늦다. 이 기록에서 평균 지연을
약 1.5초 이내로 유지하면서 새 경고를 줄이는 절충으로 1.25초를 선택했다.
이는 제품 요구사항이나 의학적 안전 기준으로 정해진 값이 아니다.

v3 → v4 프레임 혼동행렬은 TP/FP/TN/FN 기준
`444/427/5396/51` → `394/339/5484/101`이다.
최종 프레임 재현율은 약 89.7% → 79.6%로 낮아진다.
긴 눈 감김 사건을 놓치지 않았다는 결과와, 경고 대기 중 프레임이 더 많이
누락으로 계산된다는 결과를 구분해야 한다. 모든 성능 지표가 좋아진 것은 아니다.

## 이전 기록의 회귀 확인

같은 후보 모델을 각 기록에서 다시 추론하고 v3/v4 규칙을 적용했다.
기존 터미널 요약과 달리 새 모델·같은 입력 범위로 비교한 수치다.

| 기록 | 새 정상 구간 경고 v3→v4 | 평가 가능한 완료 시험 성공 v3→v4 | 평균 지연 v3→v4 |
|---|---:|---:|---:|
| session_7 | 2→0 | 4→4 | 0.499→1.236초 |
| session_8 | 7→1 | 3→4 | 1.101→1.877초 |
| session_9 | 17→7 | 1→1 | 0.562→1.339초 |

session_8에서는 시작 전 경고 중인 사건이 2회에서 1회로 줄어 평가 가능한
시험 수가 달라졌다. 평균 지연을 같은 사건들끼리의 엄밀한 비교로 볼 수 없다.
모든 기록에 시작 전 경고 중인 사건 제외 기준을 동일하게 적용했다.

## 새 촬영 session_11 확인 결과

후보 모델과 v4를 실제로 실행한 기록을 확인했다. 최소 경고 시간 1.25초,
입력 보정 `personal_baseline`, 모델 임계값 0.02가 전체 CSV에 기록되어 있다.
실제 요약은 새 경고 1회, 완료 시험 4/4 감지, 평균 첫 경고 지연 1.57초,
평균 해제 시간 1.34초였다. 정상 라벨 구간은 약 5분 36초였다.

같은 새 기록의 모델 점수를 고정한 규칙 비교:

| 지표 | v3 | v4 |
|---|---:|---:|
| 새 정상 구간 경고 | 8회 | 1회 |
| 완료 시험 성공/누락 | 4/0 | 4/0 |
| 평균 첫 경고 지연 | 0.798초 | 1.544초 |
| 평균 해제 시간 | 1.324초 | 1.324초 |
| 프레임 TP/FP/TN/FN | 488/271/5191/54 | 438/133/5329/104 |

실시간 CSV 요약의 FP는 132개지만 수신 시각으로 재생한 비교에서는 133개다.
서버 판정 시각과 수신 시각의 차이로 경계 프레임이 조금 달라질 수 있다.
이 차이를 실시간 요약값을 대체하는 결과로 해석하지 않는다.

최종 확인 기록은 v4 조건을 선택한 session_10 이후 새로 촬영했다.
이를 보고 조건을 재조정하지 않았으며, 현재 개인 환경의 시험 설정은
후보+v4로 유지하는 것을 권장한다. 모든 환경에 대한 오경보 제거를 입증한 것은 아니다.
