# 판정 규칙 변경 전후 비교

사용자 기록의 EAR, 개인별 기준값, 원시 LSTM 점수를 그대로 재생했다.
새 규칙은 높은 모델 점수만으로 경고하지 않고, 양쪽 눈의 개인 기준 대비
EAR 감소가 함께 있는 경우에만 모델 신호를 사용한다. 양쪽 눈이 확실히
열린 상태가 0.5초 유지되면 모델 점수와 관계없이 경고를 해제한다.

| 기록 | 지표 | 변경 전 | 변경 후 |
|---|---|---:|---:|
| session_8 | 최종 판정 프레임 정확도 | 42.18% | 89.45% |
| session_8 | 정상 라벨 구간 새 경고 | 37회 | 6회 |
| session_8 | 정상 라벨의 경고 프레임 | 1,520 | 232 |
| session_8 | 졸음 라벨의 누락 프레임 | 47 | 54 |
| session_8 | 평균 경고 해제 시간 | 6.133초 | 1.461초 |
| session_8 | 평가 가능한 완료 시험 성공/누락 | 3/0 | 3/0 |
| session_8 | 시험 시작 전부터 경고 중 | 2회 | 2회 |
| session_7 | 최종 판정 프레임 정확도 | 87.59% | 96.62% |
| session_7 | 정상 라벨 구간 새 경고 | 11회 | 1회 |
| session_7 | 평균 경고 해제 시간 | 2.425초 | 1.131초 |
| session_7 | 평가 가능한 완료 시험 성공/누락 | 4/0 | 4/0 |

재현:

```powershell
python model_training/compare_decisions.py backend/diagnostics/session_8_20261013_000911.csv backend/diagnostics/session_7_20261012_235458.csv
```

경고 해제 지연은 라벨 전환을 처음 수신한 프레임부터 계산한다. 키 입력
시점부터 측정하는 실시간 클라이언트 요약과 약간 다를 수 있다.
최종 프레임 지표에는 회복 중의 경고도 포함한다. 시험 시작 전 경고 중인
구간은 사건 감지 성공률과 경고 지연에서 제외한다.

이 결과는 규칙 개발에 사용한 기록을 재사용한 결과이며, 독립 검증이 아니다.
새 시간 윈도우로 LSTM을 재추론한 결과도 아니다. 모델 가중치는 변경되지
않았다. 눈을 뜬 상태의 졸음, 새로운 사용자, 카메라 또는 조명 조건의
성능은 이 비교로 입증할 수 없다. 오경보 감소와 함께 일부 졸음 라벨
프레임의 누락이 증가했으므로, 새 촬영에서도 지연과 누락을 함께 확인해야 한다.
